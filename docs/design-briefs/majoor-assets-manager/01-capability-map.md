# Majoor Assets Manager: product capability map

Audited 2026-10-29 at fork commit `1830902ce8084bc13b39b8934eb417575b3ba86f`. Design direction: **media-first professional workspace**.

## How to read this map

This maps the pinned implementation rather than claiming every feature has passed a live UI test. Each row includes source entry points. Existing structure is evidence, not a layout prescription. The page IDs refer to proposed surfaces in `02-experience-architecture.md`.

- **docs-only**: Advertised in a guide but implementation not located; do not present as working.
- **existing**: UI and/or documented implementation exists in audited source; not all paths exercised live.
- **fork**: Our custom implementation; preserve its semantics.
- **host**: Implemented but requires ComfyUI APIs, node support, browser or OS capabilities.
- **optional**: Implemented optional AI/compute capability; prerequisites and degraded states mandatory.
- **backend**: Backend/client capability found; dedicated UI not located or not established in this audit.

## Product model

The product connects five kinds of object: **physical media files**, **indexed metadata records**, **logical collections**, **execution stacks**, and **workflow documents**. A preview may be temporary; an index record may outlive its file; collection membership is not a filesystem location; a saved graph is not the current editable graph. These distinctions should shape the interface.

The core loop is **locate → inspect → compare/curate → reuse → generate → review**. Source registration and maintenance support that loop. AI enriches it when available.

## Gaps and non-goals

These must not be silently shown as already working features.

### GAP01 · Watch all character GENERATIONS roots at once
**proposed-backend** — Current watcher_scope.py resolves output or one custom root. Multiple registered roots do not mean simultaneous watchers.

### GAP02 · Auto-discover new <trigger>/GENERATIONS directories
**proposed-backend** — No verified glob-root discovery contract. Register existing real directories in current product.

### GAP03 · Unified task-centered shell and command routing
**proposed-frontend** — Recompose existing library, viewer, workflows and operations surfaces; navigation proposal is not existing route structure.

### GAP04 · Persistent saved filter rules and dynamic collections
**unverified-new-feature** — Smart ideas/clustering exist; a general automatically refreshed saved-query engine was not established.

### GAP05 · Global undo, trash browser or editing history
**unverified-new-feature** — Do not promise restoration for delete/rename/move; inspect concrete backend operations before designing undo.

### GAP06 · Full media editor, cloud sync, team accounts, model marketplace
**out-of-scope** — Not established product capabilities; viewer adjustments and save nodes are not a general editor or cloud DAM.

The catalog contains **95 capability groups**, with 151 literal backend route registrations, 100 frontend endpoint constants, 99 setting-ID definitions, and 41 Vue components in the mechanical inventory. Grouped features are intentionally not a count of buttons or endpoints.

Reviewed the README and focused guides against frontend actions, viewer controls, settings, workflow sidebar, API clients and backend handlers. Optional model compatibility and host-dependent actions still need runtime acceptance during implementation. Source inventories include developer plumbing that should not automatically become pages.
